# CivicFix

**Smart Civic Issue Reporting and Management System**

CivicFix is a web-based application developed using Flask and MySQL to help citizens report civic problems and enable administrators to manage complaints.

## Features
- Submit civic complaints
- Calculate complaint priority scores
- View and manage complaints
- Update complaint status
- Record resolution details
- Collect citizen feedback
- View analytics and high-priority issues

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Project Purpose
To provide a centralized digital platform for reporting, tracking, and managing civic issues efficiently.
