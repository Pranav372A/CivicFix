# CivicFix
## Smart Civic Issue Reporting and Management System

CivicFix is a web-based application developed using Flask and MySQL to help citizens report civic problems and enable administrators to manage complaints.

### Features
- Report civic issues such as potholes, garbage overflow, broken streetlights, and water leakage.
- Automatically calculate complaint priority scores.
- View and manage complaints through an admin dashboard.
- Track complaint statuses.
- View complaint statistics and category-wise analytics.

### Technologies Used
- Python
- Flask
- MySQL
- HTML and CSS

### Installation and Setup
1. Install Python and MySQL.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Install dependencies:

   `py -m pip install -r requirements.txt`

5. Configure your MySQL database and set the `CIVICFIX_DB_PASSWORD` environment variable to your MySQL password.
6. Run the application:

   `py app.py`

7. Open `http://127.0.0.1:5000` in your browser.

### Main Pages
- Home dashboard
- Report a complaint
- Complaint listing
- Admin dashboard
